# chat-storage 应用设置设计

## 目标

将主界面的主题切换、下载目录和服务器配置集中到独立 macOS 设置窗口，主界面只保留业务操作、连接状态、传输速度和退出入口。

## 界面

设置窗口固定为约 `720 x 480`，左侧分类为“外观、文件传输、网络连接”，右侧显示对应配置。主题支持跟随系统、浅色、深色并立即生效；下载目录复用安全书签和目录选择器；网络页显示当前连接并打开现有服务器配置界面。

## 主界面

顶部移除太阳/月亮按钮，文件工具栏移除“下载至/更改”，右上角在时间与退出之间增加齿轮设置按钮。

## 兼容性

不修改上传下载协议、服务器配置格式或文件保存逻辑。旧 `isDarkMode` 配置迁移为三态外观配置时，默认保持用户原有明暗选择。
