# chat-storage 注册窗口 UI 改造设计

## 1. 目标

将注册页面改造成与登录页面一致的横向双区界面，在现有 `720 × 456` 固定窗体内完整展示头像、四个输入字段、错误提示和注册按钮，不允许出现遮挡、裁切或依赖滚动条的情况。

本次只调整 SwiftUI 展示和局部交互，不修改注册协议、认证服务、头像编码方式或输入校验规则。

## 2. 页面结构

### 2.1 左侧品牌区

左侧宽度与登录页一致，占窗口约 40%，使用固定深色背景。

内容包括：

- “毒药网盘”品牌标记。
- 约 72pt 的圆形头像选择区。
- “创建你的专属账号”主文案。
- 一行简短说明。
- 底部“返回登录”按钮。

头像未选择时显示人物与相机图标；选中后显示裁剪后的头像。悬停头像时显示轻量编辑遮罩。头像选择和现有 `NSOpenPanel`、缩放裁剪、JPEG 编码逻辑保持不变。

### 2.2 右侧注册表单

右侧使用系统语义背景色，表单最大宽度约 310pt，按以下顺序展示：

1. 标题“创建账号”。
2. 辅助说明。
3. 用户名。
4. 密码。
5. 确认密码。
6. 邮箱。
7. 固定高度错误区域。
8. 注册按钮。

四个输入框采用约 36pt 固定高度。字段标签、输入框和字段间距使用明确数值，不能因错误提示或加载状态改变整体高度。

## 3. 交互状态

- 用户名、密码、确认密码和邮箱支持按回车依次移动焦点。
- 密码与确认密码均提供显示和隐藏按钮。
- 输入内容变化时清除旧错误。
- 错误区域始终预留高度，错误最多显示两行。
- 注册按钮使用与登录页一致的 Telegram 蓝色。
- 注册中显示进度指示和“正在注册…”，按钮尺寸不变化并阻止重复提交。
- 任意必填项为空时禁用注册按钮。
- 注册成功后继续返回登录页面。
- 左侧“返回登录”在非加载状态下始终可用。

## 4. 尺寸与防遮挡要求

- 页面固定使用 `AppWindowLayout.loginWidth` 和 `AppWindowLayout.loginHeight`。
- 不使用 `ScrollView`。
- 不保留旧页面的 `minHeight: 600`，避免与登录窗口高度冲突。
- 左右区域内部均使用固定控件高度、可控间距和边界裁剪。
- 注册按钮必须完整位于窗体内，按钮下方不再放置额外内容。
- 长错误信息最多两行并截断，不能向下挤压按钮。

## 5. 代码范围

主要修改：

- `chat-storage/RegisterView.swift`

继续保留：

- `AuthenticationService.register()` 调用。
- `InputValidator` 校验。
- `NSImage.resizeAndCrop(to:)`。
- 头像 JPEG 压缩和 Base64 编码。
- 注册成功后 `showRegister = false`。

## 6. 验收标准

- 注册页与登录页使用一致的品牌、配色、输入框和按钮风格。
- `720 × 456` 窗口内所有元素完整可见。
- 错误提示、加载状态和头像悬停状态不会造成遮挡。
- 密码显隐、焦点流转、头像选择、返回登录和注册逻辑保持可用。
- 不修改任何前后端协议定义。
