# 云盘根目录上传拦截设计

## 目标

云盘普通文件上传必须以一个有效子目录为目标。用户未选择目录、目录 ID 非正数或当前选中根目录时，不得打开文件选择器，也不得创建或提交上传任务。

聊天附件上传不使用云盘页面入口，不受本次变更影响。

## 交互规则

用户点击云盘标题栏的上传按钮时，客户端按以下顺序校验：

1. 目录树必须已加载并能取得根目录 ID。
2. `selectedDirectoryId` 必须存在。
3. `selectedDirectoryId` 必须大于 `0`。
4. `selectedDirectoryId` 不能等于根目录 ID。
5. 选中 ID 必须能在当前目录树中解析为目录节点。

任一条件不满足时，复用主界面现有“提示”弹窗，显示：

> 根目录不允许上传，请先选择一个子目录

只有全部校验通过后才打开系统文件选择器。

## 实现边界

- 将目标目录判断提取为无副作用的校验函数，返回可上传的目录节点或拒绝原因。
- 上传按钮通过该校验函数取得目标目录。
- `handleSelectFiles` 改为接收非可选目标目录。
- 删除 `targetDirectory?.id ?? 0` 和根目录名称兜底，保证无效目录不会进入 `TransferItem` 或 `StorageTransferTask`。
- 不修改 `FileTransferService`，避免把云盘页面的根目录规则扩散到聊天附件协议。
- 服务端现有 `dirId > 0` 与目录归属校验保持不变，继续作为协议安全边界。

## 测试

单元测试覆盖以下行为：

- 未选择目录时拒绝上传。
- 选中目录 ID 为 `0` 或负数时拒绝上传。
- 选中根目录时拒绝上传，即使根目录 ID 大于 `0`。
- 选中有效子目录时返回该目录并允许继续。
- 选中 ID 无法在目录树中解析时拒绝上传。

测试先验证现有代码缺少该校验能力，再实现最小逻辑使测试通过。最后运行相关单元测试和 macOS 工程构建。
